# Frontend

Клиентская часть приложения для поиска и бронирования переговорных. Реализованы список комнат, выбор офиса, фильтры, расписание комнаты, форма создания бронирования, состояния загрузки и ошибок, а также страница 404.

Кнопка «Забронировать» в карточке или на странице комнаты открывает форму. Выбранный в фильтрах интервал переносится в форму. Время указывается в часовом поясе офиса; проверяются рабочие часы, шаг 15 минут и ограничение в 30 дней. При конфликте API (409) форма сохраняет введённые данные и предлагает выбрать другое время. После подтверждения успешного создания обновляются список комнат и открытое расписание.

## Технологии

- React 19 и TypeScript;
- Vite для разработки и сборки;
- React Router для маршрутизации;
- Tailwind CSS 4 для стилей;
- Axios для запросов к API.

## Запуск

Требуется Node.js 20 или новее. Сначала запустите backend по инструкции в [`../server/README.md`](../server/README.md), затем в каталоге `client/` выполните:

```bash
npm ci
npm run dev
```

Vite выведет адрес приложения в терминал. Настройки клиента хранятся в `client/.env`. Создайте его из примера:

```powershell
Copy-Item .env.example .env
```

В `VITE_API_BASE_URL` указывается адрес REST API. WebSocket URL вычисляется из него автоматически (`http` → `ws`, `https` → `wss`, путь `/ws`). После изменения .env перезапустите Vite.

## Команды

| Команда | Назначение |
| --- | --- |
| `npm run dev` | Запустить сервер разработки Vite |
| `npm run build` | Проверить TypeScript и собрать приложение в `dist/` |
| `npm run lint` | Проверить код с ESLint |
| `npm run lint:fix` | Исправить автоматически исправимые замечания ESLint |
| `npm run preview` | Запустить локальный просмотр production-сборки |

## Структура

```text
src/
  api/rest/             HTTP-клиент и функции REST-запросов
  api/websocket/        Подключение и типы WebSocket-событий
  config/               Настройки окружения и преобразование URL
  assets/icons/         SVG-иконки
  components/
    layout/             Общая оболочка, шапка, навигация и профиль
    outlets/states/     Общие экраны состояний и их визуальные элементы
    ui/                 Переиспользуемые кнопки, поля, селекторы и скелетоны
  context/              Контексты и провайдеры
  features/Rooms/       Экран комнат, фильтры, выбор офиса и карточки комнат
  features/Bookings/    Кнопка, модалка, форма и логика создания бронирования
  hooks/                Загрузка данных и состояние API-запросов
  pages/                Страницы приложения
  types/                Общие типы данных
  utils/                Вспомогательные функции
  App.tsx               Настройка роутера и контекстов приложения
  routes.tsx            Маршруты приложения
  main.tsx              Точка входа и подключение стилей
```

Маршрут `/` перенаправляет на `/rooms`. Экран `/rooms` загружает офисы и комнаты через API, позволяет выбрать офис и передавать фильтры вместимости и времени. Неизвестные адреса показывают страницу 404.

Подробнее о REST API, WebSocket и тестовых данных — в [`../server/README.md`](../server/README.md).
